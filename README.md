# 📊 FNP Sales Performance Analysis and Dashboard (Excel)

## 📌 Overview

This project focuses on analyzing sales data of Ferns N Petals (FNP), a gifting company, to understand revenue trends, customer behavior, and product performance. The analysis is performed using Microsoft Excel, and an interactive dashboard is developed to present key business insights.

---

## 📁 Data Sources

The analysis is based on multiple datasets:

* **Orders:** Contains order details such as order date, delivery date, quantity, and occasion
* **Customers:** Includes customer location information such as city
* **Products:** Contains product details including category and price

---

## 🛠️ Tools & Techniques

* **Microsoft Excel**

  * Power Query (Data Cleaning & Transformation)
  * Pivot Tables (Data Analysis)
  * Charts & Slicers (Dashboard & Visualization)

---

## 🔄 Project Workflow

* Cleaned and transformed raw data using Power Query (handled missing values, removed duplicates, standardized formats)
* Created calculated column **Revenue = Price × Quantity**
* Extracted **month** from date fields for time-based analysis
* Merged multiple datasets and established relationships for structured analysis
* Used Pivot Tables to analyze sales by occasion, category, city, and time
* Built an interactive dashboard with KPIs and slicers for dynamic data exploration

---

## 📊 Key Insights

* Revenue is highest during major occasions such as **Anniversary** and **Raksha Bandhan**
* Certain product categories contribute significantly to total sales
* Sales show **seasonal trends** across different months
* Customer ordering patterns vary based on time and occasion

---


## 📌 Conclusion

This project demonstrates the use of Excel for end-to-end data analysis, including data cleaning, transformation, analysis, and dashboard creation. The insights derived can help businesses improve decision-making and optimize sales strategies.
